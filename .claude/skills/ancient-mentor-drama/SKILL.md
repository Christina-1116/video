# 古今拜师短剧：一条商业原理 → 3 分钟穿越短剧

```
原理 ─► ① 立意（反直觉结论 + 小事争执 + 古人 + 道具）─► ② 三招设计 ─► ③ episode.json
     ─► ④ check ─► ⑤ shotlist（分镜表 + 提示词）─► ⑥ animatic 审节奏
     ─► ⑦ 生成定妆照、镜头、配音 ─► ⑧ assemble 成片 ─► ⑨ 抽帧自检
```

`$SKILL` 指本目录。依赖：Python 3、ffmpeg（需要 libass）。
**先读**：
- `references/reference-breakdown.md`：参考片逐段拆解、单招八拍节拍、版式数值、白闪做法。
- `references/ip-bible.md`：IP 设定与画风提示词（小满、老周、范蠡的定妆提示词，信物陶碗，场景母版，师父团模板，统一负面词）。**生成任何画面前先读。**
- `references/three-moves.md`：三招库、按主题换招表、写招检查清单。
- `references/episode-schema.md`：episode.json 的每个字段。
- `examples/pricing-secret.json`：完整 3 分钟《定价的秘密》，可直接复制修改。它的产出在 `examples/pricing-secret-out/`（分镜表、提示词、字幕、样片 animatic.mp4）。
- 参考帧：仓库根目录 `docs/reference-mentor/`。拆解报告：`docs/古今拜师短剧-视频拆解.md`。

## ① 立意：先用四个默认值落地，不要追问
| 项 | 默认值 |
|---|---|
| 反直觉结论 | 一句话写成“不是 A，而是 B”，例如“价格不是成本决定的，是买家拿来比较的东西决定的” |
| 小事争执 | 一件日常商品的“价格不合理”，在便利店、奶茶店或超市里，由女儿发难 |
| 古人 | 真实历史商人：范蠡（定价、品牌）、子贡（溢价）、白圭（需求、囤积）、猗顿（盐、心理账户）、吕不韦（奇货可居） |
| 贯穿道具 | 现代商品对应一件古代同类物，再加一块写字的木牌（最好拍、最好改） |
| 规格 | 16:9，1280×720；时长 150–200 秒；50–60 个镜头 |

用一行字说明选了哪些默认值，然后直接写。

## ② 三招：结构固定，内容替换
- 三招固定为 **改名字**（换参照物 → 价格）、**留缺点**（换信任 → 溢价）、**换叫法**（换购买理由 → 需求 / 品牌）。
- 每招都走参考片的**八拍**：出题 → 按常识做 → 失败（路人反应）→ 原理上屏（“注：”加竖排口诀）→ 那怎么办 → 一个动作改道具 → 反应翻转 → 对仗点破 → 女儿领悟。每招时长 30–40 秒。
- 古人**不讲课**：每句台词 ≤ 22 个字，每招不超过 4 句。原理交给顶部“注：”条，口诀交给竖排字。
- 每招必须落在道具上（`prop_change`），并且有路人反应翻转（`reaction`）。
- 段落时长参考：现代冲突约 20 秒，白闪约 3 秒，拜见约 17 秒，三招各 30–40 秒，回闪约 4 秒，当代对照约 20 秒，收尾约 7 秒。

## ③ 写 episode.json
复制 `examples/pricing-secret.json`，依次改 `meta`、`cast`、`scenes`、`moves`、`shots`。
- 每个道具镜头都写 `prop_state`（木牌上此刻写的字）。AI 生成靠它保证前后一致。
- 两次白闪只出现在 `flash_in` 和 `flash_out` 段的最后一个镜头。触发动作要有物理接触：搭手、递碗、碰到古物。
- 当代对照用 3 个 `tag` 镜头逐一回指三招。商品使用**虚构包装**，不出现真实品牌。
- 顶部“注：”的人物介绍只写可靠的通识事实。情节属于演绎，必要时在收尾卡加“情节为演绎”。

## ④–⑥ 校验、分镜、样片
```bash
python3 $SKILL/scripts/episode.py check    ep.json              # 必须 ok，warn 也要看
python3 $SKILL/scripts/episode.py shotlist ep.json -o out/      # out/shotlist.md + out/prompts.jsonl
python3 $SKILL/scripts/episode.py subs     ep.json -o out/      # out/subs.ass + out/subs.srt
python3 $SKILL/scripts/episode.py plan     ep.json -o out/      # out/production-plan.jsonl（每镜参考节点+首帧/视频提示词）+ out/export-cues.json（LibTV export_video 字幕）
python3 $SKILL/scripts/episode.py animatic ep.json -o out/      # out/animatic.mp4：色卡 + 镜头说明 + 全部叠字 + 白闪
```
先把 `shotlist.md` 和 `animatic.mp4` 交给用户确认台词与节奏，再进入花钱的生成环节。

## ⑦ 生成素材（任选可用的生成工具；本环境可用 LibTV MCP）
1. **定妆照**：按 `references/ip-bible.md` 给每位主角出三视图、表情表和场景定妆，用 `cast.*.look` 做提示词。选定后把路径填进 `cast.*.ref`。之后所有镜头都要引用它们，保证人脸和服装一致。
2. **逐镜头首帧图**：用 `prompts.jsonl` 的 `image_prompt`，带上 `ref_images`。画面里**不要**出现字幕，字幕全部由 ASS 后期叠加。木牌、瓶标上的汉字以 `prop_state` 为准，生成后逐张核对。
3. **图生视频**：输入首帧图和 `motion_prompt`，时长取 ≥ `dur` 的最短档位，之后由 assemble 裁剪。
4. **配音**：按 `dialogue` 给每个角色定一个固定音色（女儿用清亮童声，爸爸用温和中年男声，古人用沉稳略带古韵的声音），每镜头一条音频，与画面合成为 `clips/<id>.mp4`；也可以让视频模型直接生成口型和人声。BGM 用轻快的民乐（古筝、竹笛），白闪处加一个“叮”的上扬音效。
5. 生成数量严格按镜头数，一个镜头一份；不满意只重做那一个镜头。

## ⑧ 成片
```bash
python3 $SKILL/scripts/episode.py assemble ep.json --clips clips/ --bgm bgm.mp3 --fontsdir fonts/ -o out/
```
- 素材缺失时报错；加 `--allow-missing` 会用色卡顶替，方便边生成边看。素材可以是 mp4、mov 或静帧 png、jpg。
- 素材按镜头时长裁剪或定格补齐，统一分辨率和帧率，加上白闪（出画 0.45 秒淡到白，入画 0.25 秒从白淡出），再烧录全部叠字，最后混入 BGM（默认音量 0.18，结尾 2 秒淡出）。
- 书法体：把 ttf 放进 `fonts/`，`meta.brush_font` 填字体名（如 Ma Shan Zheng、ZCOOL XiaoWei，均为免费字体）。

## ⑨ 交付前自检（必须看画面）
```bash
for t in 2 20 40 75 110 150 170; do ffmpeg -v error -y -ss $t -i out/final.mp4 -frames:v 1 out/check-$t.jpg; done
```
逐张检查：
- 人物脸和服装前后一致。
- 木牌文字与 `prop_state` 一致。
- 字幕不压住人脸。
- 顶部注释没有超出画面。
- 白闪前后正好是现代 → 古代、古代 → 现代。

交付时附上：成片、`shotlist.md`、`subs.srt`、本集 `episode.json`。

## 写作要点（拆解自参考片）
- 开场 3 秒内抛出“不合理”（“成本一块卖五块，也太黑了吧”），片名同时叠在顶部。
- 父亲只负责抛钩子和点名（“两千多年前就有人玩明白了”/“谁啊”），到古代后不再说话。
- 古人登场时先拍他在干活（擦陶罐），再抬头问“你们是？”，同时出现人物注释和竖排人名。
- 女儿把问题原样再问一遍，古人不答，只给道具和任务：“你试着卖卖看。”
- 女儿的领悟句是全集的记忆点，三招句式要统一：“原来不是……是……”。
- 结尾回到现代同一个货架，让女儿用三招重新看那件商品，最后一句收回开头的争执（“不黑，是我只看见了成本”）。
