## 一、全局画风（每个提示词末尾都要拼上）

**定调**：电影感写实，像一部高质量的国产网剧，不要像 AI 图。

**通用画风后缀**
```
电影剧照，写实摄影，ARRI Alexa 质感，35mm 胶片颗粒轻微，自然肤质（可见毛孔与细微瑕疵），柔和体积光，浅景深，焦外奶油般柔化，构图干净，色彩分级克制，16:9 宽画幅，8K 细节
```
English:
```
cinematic film still, photorealistic, shot on ARRI Alexa, subtle 35mm film grain, natural skin texture with visible pores, soft volumetric light, shallow depth of field, creamy bokeh, clean composition, restrained color grading, 16:9, highly detailed
```

**两套时空调色（冷暖对比本身就在告诉观众“穿越了”）**
| 时空 | 后缀 |
|---|---|
| 现代 | 冷白日光 5600K，青灰阴影，高调明亮，荧光灯顶光加窗边柔光，画面干净通透 |
| 古代 | 暖金色午后阳光 3200K，空气中漂浮细尘与光束，琥珀色高光，土黄与赭石为主色，微微雾化 |
| 城门黄昏 | 夕阳逆光，橙红天空，人物轮廓金边，长影子，暖到发红但肤色自然 |

**镜头语言**：近景、特写用 85mm；中景用 50mm；全景、大全景用 24–35mm。机位以平视为主，女儿的主观镜头稍微俯拍古人。

**统一负面词**
```
画面中不要出现字幕、水印、logo、真实品牌；不要卡通、动漫、3D 渲染感、塑料皮肤、过度磨皮、过饱和；手指不要畸形；服装不要左衽；古代场景不要出现现代物品（除女儿和爸爸身上的）；不要多余人物直视镜头
```
English negative:
```
text, subtitles, watermark, logo, real brand names, cartoon, anime, 3D render, plastic skin, airbrushed, oversaturated, deformed hands, extra fingers, left-over-right collar, modern objects in ancient scene, background people staring at camera
```

## 六、用法要点
1. 先出三位主角的三视图，每人至少出 4 版，选一版后**锁定**。
2. 之后所有镜头都带上对应角色的三视图当参考图，并把“外形基础描述”原样拼进提示词。描述里的一个字都不要改，改了就会漂移。
3. 每个镜头的提示词按这个顺序拼接：景别 → 场景 → 人物动作 → 道具状态 → 人物外形基础描述 → 通用画风后缀 → 时空调色 → 负面词。`episode.py shotlist` 会自动完成。
4. 古代群演只写“粗麻短褐、头裹布巾”，不要给他们写具体长相，免得抢戏。
