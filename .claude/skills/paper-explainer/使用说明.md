# paper-explainer 技能包使用说明

输入一个主题，直接生成一部**可播放的 HTML 讲解短片**。成片包含：
- 纸艺风格插图和流畅的动画；
- 英文配音和背景音乐；
- 字幕，可切换中英双语、只英文、只中文或关闭；
- 播放控件：进度条、重播、倍速、全文稿、键盘快捷键和无障碍设置。

需要的话还可以导出 MP4。

## 五种内置风格（全部包含在本包里）
| 风格 | 名称 | 适合 |
|---|---|---|
| `collage` | 拼贴杂志：灰纸纹、撕边黄色标题条、网点贴纸、底部年代时间轴 | 历史、演变、时间线 |
| `papercraft` | 纸艺几何：米色纸、角落撕边纸片、衬线标题卡 | 数学、物理、逐步推导 |
| `papermap` | 纸艺地图：鼠尾草绿地图板、纸片地貌、会生长和变形的河流或道路 | 地理、自然过程 |
| `nightpaper` | 夜色纸艺：深色纸、暖色和青色点缀 | 科技、产品 |
| `blueprint` | 蓝图纸艺：深蓝底、浅色纸片、珊瑚红点缀 | 工程、航空 |

效果对比：`gallery/styles-takeoff.png` 是同一个起飞视频在 4 种风格下的画面，其余图片是各个示例的故事板。

还可以自定义新风格：在故事文件的 `meta` 里改 `palette`（配色）和 `styleOverrides`（标题、背景、阴影的样式），不需要改代码。

## 怎么安装
- **Claude Code**：把 `paper-explainer` 文件夹放进 `~/.claude/skills/`。
- **Claude.ai 或 Claude 桌面版**：设置 → Capabilities → Skills → Upload skill，上传 zip 包。
- **其他 AI 工具**：让它读 `SKILL.md` 并按里面的流程执行即可。

安装好后，直接对 AI 说：
> 用 paper-explainer 做一个「为什么天空是蓝色的」视频，papercraft 风格，英文配音，中英双语字幕，右下角水印 by XXX

## 环境要求
| 用途 | 需要 |
|---|---|
| 生成 HTML 视频 | Python 3 |
| 预览故事板、导出 MP4 | Node 18 及以上、Playwright（Chromium）、ffmpeg |
| 录制英文配音（推荐） | `pip install kokoro-onnx soundfile`，外加模型文件 `kokoro-v1.0.onnx` 和 `voices-v1.0.bin`（在 GitHub 上 thewh1teagle/kokoro-onnx 的 releases 页，标签 model-files-v1.0，约 350 MB） |

如果没有录制配音，播放时会自动改用浏览器自带的语音朗读，但不同设备上的音色会不一样。想让所有人听到同一个声音，就先录好配音，再打包进 HTML。

## 包里有什么
```
SKILL.md                 给 AI 看的完整工作流
使用说明.md / INSTALL.md   给人看的说明
runtime/                 播放器（styles.js 定义五种风格和 48 个图标）
scripts/                 build.py 生成 HTML · preview.js 故事板预览 · tts.py 录配音 · export_mp4.js 导出 MP4
references/              故事文件字段说明、风格指南
examples/                money（collage）· pythagoras（papercraft）· delta（papermap）· takeoff（起飞，中英双语字幕）
gallery/                 风格效果图
```
